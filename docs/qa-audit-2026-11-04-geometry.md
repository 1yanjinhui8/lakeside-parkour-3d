### A3 为什么 AABB 会错

`tools/gen-blockers.py` 用 `Polygon(cs).bounds` 取**未裁剪的 OSM 原始多边形**外包盒。
2026-10-31 返工时楼体是用 shapely 从走廊里 `clip_building` 切掉的，**切的是底板几何，不是这张表**。
旋转 / L 形 / 大进深的楼，轴对齐外包盒必然覆盖拐角。
→ 影响仅限于 `art.js` 的 `blocked(x,z,pad)` **过度避让**（这些路段少摆几棵树/灯），**不是玩家可见缺陷**。

### D3 一处方法失效（必须写明，不得当数据用）

探针算出的 `feetY ∈ [-0.946, -0.914]` **不可用**：`character.glb` 是 `SkinnedMesh`（36304 顶点 / 17 骨骼），
几何体顶点是**绑定姿势**坐标、未经蒙皮变换，`matrixWorld × 顶点 ≠ 渲染位置`
（同一探针打印的绑定姿势 bbox 为 `y ∈ [-0.96, 2.81]`、水平跨度 4.6m 四肢张开，与「1.85m 高、脚在 0」直接矛盾）。
→ 该项以近景帧为准：制作人代拍 `char-body.png` 实测包围盒 **y 0.02~1.87**，脚底与路面齐平。
